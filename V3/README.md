# olivierbourgault.github.io — Version 3 (V3)

Ce dossier contient la **Version 3 (édition Fuchsia & Améthyste)** de mon portfolio ([https://olivierbourgault.github.io/V3/](https://olivierbourgault.github.io/V3/)).
En plus de l'ensemble du contenu enrichi de la V2, cette version introduit une refonte visuelle complète :
- **Mode Clair** : Fond blanc perle lavande (`#FAF7FD`), accents rose fuchsia (`#D946EF`) et mauve profond (`#9333EA`), texte aubergine (`#181124`).
- **Mode Sombre** : Fond noir améthyste (`#0A0812`), accents rose néon (`#E11484`) et mauve électrique (`#A855F7`), grille subtile, halos diffus (`blur(45px)`) et cartes en glassmorphisme.

Le code du site se trouve dans [`index.html`](index.html) et dépend des ressources situées dans le dossier [`./assets`](assets/). Ce site est inspiré d'un [modèle](assets/README.md) en ligne.
