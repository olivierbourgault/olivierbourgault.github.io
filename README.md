## Structure du dépôt

Ce répertoire organise mon portfolio par versions afin de conserver l'historique complet de ses évolutions :

- **[`index.html`](index.html)** : Portail d'entrée interactif permettant de naviguer entre les différentes versions du site (`V1`, `V2`, `V3`, et les futures versions `V4+`).
- **[`V3/`](V3/index.html)** *(Recommandée)* : Refonte visuelle complète avec une nouvelle direction artistique (Mode Clair Lavande/Fuchsia & Mode Sombre Améthyste/Néon, halos diffus et cartes en glassmorphisme) intégrant l'ensemble du contenu enrichi.
- **[`V2/`](V2/index.html)** *(Stable)* : Version enrichie intégrant mon parcours en intelligence artificielle (AEC au Collège O'Sullivan), mes expériences récentes (Élections Canada, Microsoft Learn), mes nouvelles compétences techniques et des fiches de projets détaillées avec badges.
- **[`V1/`](V1/index.html)** *(Archive)* : Version initiale de mon portfolio (sauvegarde complète avec ses `assets`).
