# olivierbourgault.github.io — Version 5 (V5 Tech Canvas Edition)

Ce dossier contient la **Version 5 (Édition Tech Canvas & Néo-Brutalisme)** de mon portfolio Web ([https://olivierbourgault.github.io/V5/](https://olivierbourgault.github.io/V5/)).

## 🎯 Nouveautés de la Version 5.0

1. **Direction Artistique « Tech Canvas » Activée par Défaut** :
   - Fusionne l'identité technique **Tech** (orange `#FF6600` et fond carbone `#121316`), l'atelier Figma/papier de [Shabnam Raghavan](https://www.shabnamraghavan.com/) et le design néo-brutaliste interactif d'[Aahil Khan](https://www.aahil-khan.xyz/).
   - Trame de découpe géométrique subtile en arrière-plan (`48px × 48px`).

2. **Hero Style Planche de Découpe & Cadre Figma** :
   - Conteneur Hero doté d'une bordure franche orange `#FF6600` et d'une ombre décalée néo-brutaliste (`8px 8px 0px #000000`).
   - Titre principal encadré d'une boîte de sélection vectorielle Figma orange avec poignée carrée et étiquette de calque `TECH · CANVAS · OS`.
   - Surlignage dactylo dynamique au marqueur contrasté sur l'animation de frappe.

3. **Cartes Néo-Brutalistes & Ruban Adhésif d'Atelier** :
   - Cartes de projets, expertises et compétences dotées de bordures de `2px`, d'ombres portées dures décalées (`5px 5px 0px #FF6600`) et d'un ruban adhésif translucide ambre/orange texturé au centre supérieur.
   - Statistiques KPI présentées sous forme de tuiles post-it inclinées interactives.

4. **Style Dédié Exclusif « Tech Canvas »** :
   - Élimination des autres palettes annexes pour cette version : l'identité visuelle est désormais 100% dédiée au design **Tech Canvas**, offrant une expérience cohérente, affirmée et épurée.
   - Retrait du sélecteur flottant de palettes pour libérer totalement le bas d'écran.
   - Pointeur laser virtuel toujours activable au clavier via le raccourci `L`.

6. **Typographies Avancées** :
   - Intégration harmonieuse de `Space Grotesk`, `Manrope`, `Inter` et `JetBrains Mono`.

Le code du site se trouve dans [`index.html`](index.html) et dépend des ressources situées dans le dossier [`./assets`](assets/).
